# Muse 吧唧 v1.1（ESP32-S3-Touch-AMOLED-1.75C）

v1.1 新增：**Opus 录音**（不再是 WAV）、**边录边传**（录音实时推到 Mac）、
**录音自动熄屏**、**Wi-Fi 配网页面**。动画播放和按键操作与 v1 相同。

## 一、烧录

1. USB-C 数据线把板子接上 Mac。
2. 在本文件夹打开终端，运行：`bash flash.sh`
3. 烧完板子自动重启。

## 二、首次开机：配网（只做一次）

v1.1 出厂没有 Wi-Fi 信息，第一次开机会进入配网模式：

1. 屏幕显示 SETUP 时，用手机或 Mac 连 Wi-Fi 热点 **MuseBadge-Setup**。
2. 浏览器打开 **192.168.4.1**，填家里/办公室的 Wi-Fi 名和密码，点保存。
3. 板子自动重启并连上你的 Wi-Fi，吉祥物动画出现即完成。

之后换网络：开机时按住 BOOT 键约 2 秒，配网信息会被清除，重新进入配网模式。
（密码只存在板子里，不经过任何服务器。）

## 三、操作

- **短按 BOOT**：切换吉祥物状态（待机/工作/做东西/连接中/庆祝/等帮手）。
- **长按 BOOT（1.2 秒）**：开始录音；再长按一次停止。
- 录音开始 3 秒后**屏幕自动熄灭**（省电、不打扰）；录音中短按 BOOT 可亮屏
  查看 3 秒（屏幕上会显示 streaming / local only）；到 2 小时自动停；
  存储快满也会自动停。
- 录音格式：Opus 16kbps，本地存为 `.ogg` 主本，约 2 小时/15MB。

## 四、边录边传（Mac 接收端）

1. Mac 和吧唧连同一个 Wi-Fi。
2. 在 Mac 终端运行：`python3 badge_receiver.py`，保持窗口开着。
3. 吧唧一开始录音就会自动找到接收端并实时推流；录完的文件在
   `~/Downloads/muse-badge-recordings/`，是标准 `.ogg`，可直接播放。
4. 如果装了「吧唧录音库 BadgePod」，录完的文件会自动投进它的收件箱，
   自动转写、生成纪要，不用再手动导入。
5. 接收端没开或不在同一网络也没关系：吧唧本地主本照常录，
   只是没有实时副本（屏幕显示 local only）。

## 五、这次要验的点（v1 首验 + v1.1 新项）

1. 动画颜色对不对（红蓝反了告诉我，改一个开关重编）。
2. BOOT 短按能否切状态、长按能否启停录音。
3. 录音有没有声、双麦拾音清不清楚（听接收端收到的 .ogg 最方便）。
4. 屏幕电量百分比准不准。
5. 配网流程是否顺畅；录音 3 秒后是否熄屏、短按是否能唤醒。
6. 接收端窗口是否显示「接收中」、录完文件是否落盘/进豆仓。

## 已知边界

- 录音导出仍只有边录边传这一条路；没传成的录音留在吧唧本地，
  暂时没有补传功能（本地主本不会丢，下一版做 USB/快传导出）。
- 两次录音之间请隔几秒再开始，上一段的推流收尾更干净
  （本地主本不受影响，始终完整）。
- 触摸切状态、与 Muse 实时状态联动，仍在后续版本。
